# 나라장터 공고명 정밀화 및 RFP 접근성 계획

> **목적**: 실제 나라장터 수집에서 발견된 광범위한 `환경`·`검토`·`인증` 오탐을 줄이면서, 애매한 공고와 원문 증거는 삭제하지 않고 사람이 확인할 수 있게 한다.
>
> **기준일**: 2026-09-21

## 현재 상황

- 실제 나라장터 3일 수집은 정상 동작했고, 초기 40건이 저장되었다.
- 공고명과 무관하게 발주기관명에 `환경`이 포함된 보안·IT 공고도 후보가 되는 사례가 확인되었다.
- 나라장터 목록 API는 공고 원문 URL은 제공하지만, 공개 첨부 RFP/과업지시서의 직접 URL은 제공하지 않는 경우가 있다.

## 계획

1. 나라장터 관련성은 공고명만으로 1차 판단한다.
2. 기후·온실가스·배출권·ESG·리스크의 강한 신호 또는 구체적 환경 업무와 컨설팅/조사/평가 신호가 함께 있을 때 일반 후보로 둔다.
3. `환경`, `검토`, `인증`처럼 단독으로는 넓은 신호는 `needs_review` 대기열로 저장하고 자동 메일·브리핑에서는 제외한다.
4. 공고명에 도메인 신호가 전혀 없는 기존 후보도 삭제하지 않고 같은 대기열로 표시한다.
5. 나라장터 문서 링크가 없을 때는 “RFP 없음”이라고 판단하지 않고, 문서 인덱스에서 원문 `파일첨부` 확인 링크를 제공한다.

## 성공 기준

- 기관명에만 `환경`이 있는 보안 공고는 일반 알림 후보가 되지 않는다.
- `CDPR` 같은 단어가 `CDP`로 잘못 매칭되지 않는다.
- 애매한 환경 공고는 대시보드에 보존되며, 즉시·일일·주간 알림에는 포함되지 않는다.
- 기존 공고 원문, 수집 시각, 첨부 기록, 발송 기록을 삭제하거나 변경하지 않는다.

## 범위 밖

- 공개 페이지의 보호된 다운로드 토큰을 재구성하거나 로그인·CAPTCHA·접근 제한을 우회하지 않는다.
- RFP 원문 파일을 대량 다운로드하거나 자동으로 입찰 적합성을 판정하지 않는다.
