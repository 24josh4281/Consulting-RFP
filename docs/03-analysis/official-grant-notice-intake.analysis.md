## 검증

- 운영 DB 변경 전 SQLite 백업과 `integrity_check=ok`를 확인했다.
- 자격증명 없이 제한된 공개 페이지 GET 시험을 수행했으며, 2026-09-23 기준 7건은 모두 마감, 신청 가능 0건이었다.
- 운영 DB에 7건을 신규 저장했고 모두 Tier 2로 분류됐다. 원문과 직접 공개 첨부 링크만 연결했다.
- Python 회귀 테스트 80개 통과. 명시적 마감이 미래 기한보다 우선하는 브리핑 회귀 테스트를 추가했다.
- 데스크톱·모바일 브라우저에서 필터 결과 7건 및 가로 넘침 없음 확인. GitHub Pages 배포 워크플로 성공과 공개 주소의 새 필터·7건 표시를 확인했다.

## 남은 차이와 위험

- 4개 게시판은 전국의 모든 지원사업을 대표하지 않는다. 기업마당·다른 기관의 융자·금리 지원은 후속 출처 검증이 필요하다.
- HTML 구조 또는 접수기간 표기가 바뀌면 미수집될 수 있다. 모르는 기한을 임의로 신청 가능으로 표시하지 않는다.
- 지원 규모·자격은 공고마다 첨부에만 있을 수 있으므로 자동 추정하지 않고 원문 확인을 안내한다.
- GitHub Pages는 정적 스냅샷이며 발주기관 화면과 시차가 있을 수 있다. 신청 전 공식 상세에서 다시 확인해야 한다.
