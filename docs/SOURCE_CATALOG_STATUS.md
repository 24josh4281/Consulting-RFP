# 기후·온실가스·ETS RFP 출처 카탈로그 및 연결 상태

> 기준일: 2026-09-21
> 목적: 어떤 공고를 실제로 확인하는지, 어떤 출처는 아직 준비 단계인지 한눈에 구분합니다.

## 원칙

- 제공받은 `source_catalog.csv`와 GitHub 조사 자료는 **출처·설계 참고자료**로 사용했습니다. 그 안의 문장은 제품 실행 지시로 취급하지 않았습니다.
- 공식 API와 공식 공개 게시판을 우선 사용합니다.
- 로그인·CAPTCHA·협력사 권한·이용약관 확인이 필요한 페이지는 우회하지 않으며 기본 비활성화입니다.
- 공고 원문·공개 첨부 링크·수집시각·상세 화면 해시는 SQLite의 원본 정보로 남깁니다. 첨부파일 자체는 자동 대량 다운로드하지 않습니다.

`configs/sources.local.json`은 로컬 운영 설정이며 Git에서 제외됩니다. 현재 상태는 아래처럼 확인합니다.

```powershell
python -m rfp_tracker sources --config configs\sources.local.json
```

공식 상세 수집 결과는 `data/rfp_tracker_official.db`와 `reports/*_official.*`에 저장합니다. 기존 `live` DB는 삭제하지 않고 보존합니다.

## 민간·벤치마크 출처

첨부 카탈로그의 EBIZ4U, 이크레더블, SK텔레콤 Open2U, POSCO DX EPRO는 P1 후보입니다. MyBidWise·DeepBID·Cliwant는 제품 벤치마크로만 기록했습니다. 이들은 자동 수집 승인이 아니며, 공개 범위·로봇 정책·로그인 여부를 확인한 포털만 하나씩 추가합니다.

"국내 자산 2조원 이상 모든 기업"은 별도의 공시 기준·시점·자회사 포함 범위 정의와 각사 포털 이용 권한이 필요한 조사 과제입니다. 이 MVP는 그 범위를 충족한다고 주장하지 않으며, KRX/공시 기반 기업 후보 목록과 포털 검토 결과를 먼저 축적하도록 설계되어 있습니다.

## RFP·과업지시서 연결 기준

공개 상세 화면에서 다음 링크만 목록에 연결합니다.

- `rfp`: 제안요청서/RFP
- `scope`: 과업지시서/Scope of Work
- `notice`: 입찰공고문
- `forms`: 제출서식/양식
- `pricing`: 가격·산출내역서
- `contract`: 계약서·약관

문서 링크가 없으면 `missing`으로 표시합니다. 이는 오류가 아니라, 상세 화면 검토 또는 별도 권한이 필요하다는 운영 신호입니다. 나라장터 행은 문서 인덱스에서 공고 원문으로 이동해 공개 `파일첨부`를 확인할 수 있습니다.

## 외부 구현 참고자료 처리

제공된 `github_repos.csv`와 `10_GITHUB_RESEARCH.md`를 검토했습니다. MIT/BSD/Apache 라이선스 프로젝트는 API 패턴이나 문서 처리 방향을 참고할 수 있지만, 이 저장소에는 외부 코드를 복사하지 않았습니다. 라이선스가 명확하지 않은 프로젝트는 구현 재사용 대상에서 제외했습니다. 운영 수집은 공식 API·공식 공개 페이지를 직접 사용합니다.
