# 나라장터 공고명 정밀화 및 RFP 접근성 설계

> **상태**: 구현 및 실제 API 검증 완료
>
> **기준일**: 2026-09-21

## 판단 흐름

```text
나라장터 API 공고명
        |
  공고명에 도메인 신호가 있는가?
   | 없음                    | 있음
needs_review              강한 기후/GHG/ETS/ESG/리스크인가?
   |                         | 예
대시보드 보존              new → 일반 보고·알림
자동 메일 제외             |
                     아니오: 구체적 환경 + 업무성 신호인가?
                                  | 예                 | 아니오
                               new               needs_review
```

## 규칙

- **강한 그룹**: 기후, GHG, ETS, ESG 보고, 기후리스크 관련 키워드.
- **구체적 환경 + 업무성**: 환경영향평가·수질·대기배출·자원순환 등과 컨설팅·조사·평가·설계·개발 등 업무성 단어가 함께 있는 경우.
- **검토 대기열**: 일반 `환경` 또는 보조 단어만 있는 경우. SQLite `review_status=needs_review`로 저장한다.
- **알림 안전장치**: 즉시 알림과 브리핑 조회는 `needs_review`를 제외한다. 사람이 `interesting`, `watch`, `new` 등으로 바꾸면 일반 검토 흐름으로 되돌릴 수 있다.
- **영문 약어**: CDP/LCA/ETS 등은 단어 경계를 적용해 긴 단어 일부로 오인하지 않는다.

## RFP 접근성

- GIR 공개 게시판은 수집 가능한 RFP/과업지시서 링크를 직접 문서 인덱스에 연결한다.
- 나라장터 목록 API에서 첨부 URL이 없으면 문서 인덱스는 공고 원문 URL을 제공하고, `파일첨부`에서 확인하도록 명시한다.
- 공고 원문과 SQLite 원본 JSON은 보존한다. 보호된 다운로드 경로를 역추적하거나 파일을 자동 다운로드하지 않는다.
