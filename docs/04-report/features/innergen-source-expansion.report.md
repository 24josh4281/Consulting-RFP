# 이너젠 지원사업 출처 확장 — PDCA Report

> 완료 범위: 2026-09-23 · 제한적 통합. 모든 후보 출처의 실운영 개시는 아님.

## 완료

- KEITI·KICoX 공개 게시판 연결기와 기업마당 공식 API 연결기를 추가했다.
- 고객사 지원사업은 직접 입찰과 구분해 Tier 2로 분류하며, 기술개발·행사·공급업체 입찰 등은 제목 증거에 따라 제외한다.
- KEITI만 로컬 정기 수집 ON. KICoX는 HTTPS 문제, 기업마당은 별도 인증키·공개 조건 확인 전까지 OFF.
- 기업마당 원문 설명과 API 키는 공개 데이터에 복제하지 않으며, 신청기한 미확인은 활성 공고가 아니다.

## 검증

자동 테스트 86개 통과. KEITI 공식 목록 2쪽 실조회 성공, 3일 창 적합 후보 0건. 활성 지원사업 게시판 5개를 임시 메모리 DB로 수집해 전체 0건·오류 0건 확인. 운영 DB·메일은 변경하지 않았다. 공개 웹사이트에 새 공고가 생겼다고 주장하지 않는다.

## 운영 후속

1. [기업마당 API](https://www.bizinfo.go.kr/apiDetail.do?id=bizinfoApi)에서 별도 키와 게시·재이용 조건을 확인한다. 조건 충족 뒤에만 로컬 `.env`와 `configs/sources.local.json`을 갱신한다.
2. KICoX Python HTTPS 연결 원인을 조사하되 TLS 검증은 유지한다.
3. 새 KEITI 공고가 수집되면 제목·신청기한·원문 링크와 지원 자격을 사람이 확인한다.
4. 중소기업24/과기정통부/IRIS는 중복·순수 과학 노이즈를 수치로 평가한 다음 추가 여부를 결정한다.
