# 공식 탄소중립 설비 지원사업 수집 완료 보고

> 완료일: 2026-09-23 · PDCA Report

## 완료한 작업

- 나라장터의 설비 구매입찰과 고객사 지원금 신청 모집을 별도 공고 유형으로 분리했다.
- 중진공 1곳, 한국환경공단 1곳, 한국에너지공단 2곳의 공식 공개 게시판을 제한 수집하도록 연결했다.
- 운영 DB를 안전하게 백업한 뒤 실제 지원사업 공고 7건을 추가했고, 공개 대시보드에 유형 필터와 ‘지원사업 전체 보기’를 배포했다.
- 메일에서는 신청 가능한 Tier 2만 고객사 추천 영역에 포함되며, 지원 규모가 없는 경우 임의 금액 대신 원문 확인을 표시한다. 이번 변경 작업에서 메일을 발송하지는 않았다.

## 검증 결과

| 항목 | 결과 |
|---|---|
| 자동 테스트 | 80개 통과 |
| 운영 DB | 신규 7건, 전부 Tier 2, 무결성 `ok` |
| 신청 가능 현황 | 2026-09-23 기준 0건; 7건 모두 마감 |
| 대시보드 | 데스크톱·모바일에서 지원사업 7건 필터 확인 |
| 공개 배포 | GitHub `main` 및 Pages 배포 성공; 공개 URL에서 새 유형 필터·7건 확인 |
| 비밀정보 | 공개 HTML에서 API 키·SMTP 값·수신자·내부 검토 메모 미검출 |

## 운영·남은 과제

- 로컬 `configs/sources.local.json`의 4개 지원사업 출처를 활성화했다. 정기 수집은 기존 알림 실행 흐름에서 이어진다.
- 대시보드는 [공개 주소](https://24josh4281.github.io/Consulting-RFP/)에서 확인한다. 신청 전에는 반드시 각 공고 원문에서 기한·대상·자격·지원 규모를 재확인한다.
- 기타 공공 지원기관과 금융지원 공고까지 확대하려면 출처별 공개 범위·구조를 검토한 후 별도 어댑터를 추가해야 한다.
