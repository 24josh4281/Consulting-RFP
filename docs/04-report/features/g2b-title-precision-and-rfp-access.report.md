## 결과

- 실제 나라장터 API 재수집에서 공고명 기준 후보 **14건**을 확인했고, 새 공고 1건을 저장했다.
- 현재 나라장터 저장 공고 41건을 감사한 결과: 강한 후보 7건, 사람 검토 7건, 공고명 도메인 신호 없음 27건이었다.
- 기존의 일반 후보 34건은 삭제하지 않고 `needs_review` 상태로 전환했다. 원문, 첨부 기록, 수집 시각, 메일 발송 기록은 모두 유지했다.
- 기존 전체 DB는 46건이며, 일반 알림/브리핑 대상은 12건, 검토 대기열은 34건이다.
- 나라장터 문서 인덱스의 미수집 행은 공고 원문 `파일첨부` 확인 링크를 표시하도록 개선했다.

## 남은 제한과 다음 단계

- 나라장터 목록 API에는 공개 첨부 URL이 항상 포함되지 않는다. 현재는 공고 원문으로 바로 이동해 RFP·과업지시서를 확인할 수 있다.
- 직접 첨부 메타데이터를 자동 연결하려면 공공데이터포털의 공식 상세 API 계약을 확인한 뒤, 별도 저속·읽기 전용 연결기를 추가해야 한다.
- 환경부와 민간 대기업 포털은 공개 범위·약관·로그인 요구사항을 확인하기 전까지 비활성화 상태를 유지한다.
